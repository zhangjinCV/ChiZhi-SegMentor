# 品牌素材 / Brand assets

本目录包含炽智实验室（CHIZHI LAB）提供的标识素材：

| 文件 | 用途 |
|---|---|
| `chizhi-mark.png` | 透明背景彩色标识（README、界面） |
| `chizhi-lockup-light.png` | 浅色背景 lockup（炽智实验室 / CHIZHI LAB） |
| `chizhi-lockup-dark.png` | 深色背景 lockup |
| `chizhi-lockup-descriptor.png` | 带实验室定位语的 lockup |
| `chizhi-logo.svg` | 矢量源文件 |

应用内图标由 `06_icon_square_1024.png` 生成，位于：

- `apps/web/public/favicon.png`
- `apps/web/public/chizhi-mark-128.png`
- `apps/desktop/build/icon.png` / `icon.ico`

## 使用规则

- 炽智实验室标识、中文名“炽智实验室”、英文名“CHIZHI LAB”以及 lockup 归炽智实验室所有，**不包含在 Apache-2.0 代码许可内**。
- 在 README、软件界面、论文或演示中引用本项目时，请保留实验室标识与名称，不要修改 logo 的比例、颜色或组成。
- 二次开发/再分发时，请保留 `README.md` 顶部的实验室 lockup 与“炽智实验室 CHIZHI LAB”署名。
- 如需将标识用于商业发布、联合品牌或其他用途，请先联系炽智实验室。

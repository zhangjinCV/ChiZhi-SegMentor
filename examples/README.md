# 示例项目 / Examples

当前仓库**不附带**可直接再分发的实拍图片，因为 `tank_annotated` 等数据的再分发许可尚未确认。

本地体验推荐：

1. 使用自己的图片 + VOC/COCO 标注；
2. 或在获得许可后，从本机 `tank_annotated` 数据副本复制少量图片/XML 到本目录（不要提交到公开仓库）；
3. 批量页：
   - 图片文件夹：`.../JPEGImages`
   - 标注文件夹：`.../Annotations`
   - 格式：自动检测（VOC）
   - 先解析预览，再跑 3–5 张确认参数。

正式发布前，建议补充一个可再分发的小示例（例如自摄/合成图 + 标注 + 预期 mask），让用户打开即可体验。

## 数据许可提醒

- 图片、标注、mask 的版权/许可与代码（Apache-2.0）独立。
- 公开示例必须确认可再分发；不要直接提交本机研究数据目录下的原始数据。
